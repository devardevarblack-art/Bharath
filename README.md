# Organ Donate - Smart Organ Donation and Transplant Management System

## 📋 Project Overview
Organ Donate is a comprehensive web-based system designed to streamline organ donation and transplant management. The system facilitates connections between donors, patients, hospitals, and administrators to ensure efficient organ matching and transplantation.

## 🏗️ Technology Stack

### Frontend
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

### Backend
- PHP 8
- RESTful API

### Database
- MySQL

### Server
- XAMPP / Apache

## 👥 User Roles

### 1. Admin
- Secure Login (No Registration)
- Dashboard Management
- Manage Donors, Patients, Hospitals
- Approve Donor & Hospital Accounts
- Monitor Organ Requests
- Generate Reports

### 2. Donor
- Registration & Login
- Profile Management
- Organ Donation Registration
- View Donation History
- Track Status

### 3. Patient
- Registration & Login
- Request Organ
- Track Request Status
- View Matched Donors
- Receive Notifications

### 4. Hospital
- Registration & Login (requires Admin Approval)
- Verify Patients & Donors
- Manage Organ Availability
- Approve Transplants

## 🚀 Installation & Setup

1. Clone Repository
2. Setup Database
3. Configure Database Connection
4. Run Application at http://localhost/Bharath
