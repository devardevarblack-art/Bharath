# Organ Donate - Smart Organ Donation and Transplant Management System

## Final Year Project

A comprehensive web-based system for managing organ donations and transplants with roles for Admin, Donors, Patients, and Hospitals.

### Technology Stack
- **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
- **Backend:** PHP 8
- **Database:** MySQL
- **Server:** XAMPP

### Project Structure
- `/frontend` - HTML, CSS, JavaScript files
- `/backend` - PHP backend code
- `/database` - SQL database scripts
- `/documentation` - Project documentation
